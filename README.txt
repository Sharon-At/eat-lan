eat.lan site

מה בפנים:
- index.html עם 133 כרטיסים.
- תיקיית images עם כל התמונות החתוכות.
- עמוד נפרד לכל מתכון.
- partials/header.html ו-partials/footer.html.
- scripts/include.js ו-scripts/main.js.

הרצה:
1. לפתוח את התיקייה ב-VS Code.
2. קליק ימני על index.html.
3. Open with Live Server.

הערה: חלק מהתמונות הגיעו כצילומי מסך של אינסטגרם, ולכן החיתוך נעשה מתוך הצילום עצמו. חלק קטן מהתמונות שהיו Reels עדיין עשויות להכיל אזורים צדדיים מהצילום, אבל מסגרת האינסטגרם העיקרית הוסרה ככל האפשר בחיתוך אוטומטי.
